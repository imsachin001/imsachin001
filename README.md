### 🤖 AI Resume Analyzer

AI-powered resume analysis platform that evaluates resumes against job descriptions and provides ATS-focused feedback.

**Highlights**
- Built REST APIs using **Node.js + Express**
- Integrated **Gemini AI** for resume analysis and job-description matching
- Implemented **Redis caching** using SHA-256 based cache keys
- Added **BullMQ background processing** for asynchronous resume analysis
- Added API/worker observability for **latency, queue wait and processing time**
- Deployed using a modern **React + Node.js architecture**

**Tech:** React • Node.js • Express • MongoDB • Redis • BullMQ • Gemini
